## ??? How to Run Locally

Clone and navigate into the repository:
```bash
git clone https://github.com/sadeepas/day029-express-api-types.git
cd day029-express-api-types
```

Run the entry point according to your environment:
- **Python**: `python main.py` or `python solution.py`
- **JavaScript / TypeScript**: `node app.js` or `npx ts-node app.ts`
- **C++**: `g++ -std=c++20 main.cpp -o app.exe && ./app.exe`
- **C#**: `dotnet run`
- **HTML / CSS**: Open `index.html` in your browser.
